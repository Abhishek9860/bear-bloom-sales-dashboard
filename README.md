Bear & Bloom --- E-Commerce Sales Analytics Dashboard
Project Overview
Bear & Bloom is a portfolio project built in Microsoft Power BI using a
sample e-commerce dataset. It explores sales performance, marketing
traffic, and product profitability through three dashboard pages.
Dashboard Pages
1. Executive Overview
- Total orders, revenue, gross profit, gross profit margin, and
  average order value
- Monthly and yearly revenue trends
- Revenue by product
- Orders by device type
2. Marketing Performance
- Total website sessions and orders
- Session conversion rate
- Sessions by traffic source
- Conversion rate by traffic source
- Monthly website sessions
3. Product Performance
- Total items sold
- Product revenue and gross profit
- Product gross margin
- Product-level comparisons for revenue, profit, margin, and sales
  volume
Tools and Skills
- Microsoft Power BI
- DAX measures and KPI calculations
- Data modeling and relationships
- Data visualization and dashboard design
- Exploratory business analysis
Business Questions
- How did revenue change over time?
- Which products generated the most revenue and gross profit?
- How did gross margins compare across products?
- Which traffic sources generated the most website sessions?
- How did session conversion rates differ by traffic source?

Data Source
This project uses a sample e-commerce dataset for learning and portfolio
development. The analysis covers orders, order items, products, website
sessions, and website pageviews.
Notes
- The dataset contains traffic-source values such as NULL; these are
  retained as categories in the current report.
- The latest month in the sales dataset may be incomplete, so
  partial-period results should be interpreted carefully.
- Dashboard totals should be interpreted in the context of the
  underlying data model and measure definitions.
